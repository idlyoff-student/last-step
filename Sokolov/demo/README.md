# Coffee Shop v2

Добавлено:
- вход в учётную запись;
- хеширование пароля и ответа на секретный вопрос;
- восстановление пароля через секретный вопрос;
- отдельный публичный экран `/display` для монитора/телевизора;
- экран автоматически обновляется каждые 5 секунд.

Первый вход:
`admin` / `admin123`

Секретный вопрос:
`Как называется ваш любимый напиток?`

Ответ:
`кофе`

Установка:
`pip install -r requirements.txt`

Запуск:
`python app.py`

Основная система: `http://127.0.0.1:5000`
Экран: `http://127.0.0.1:5000/display`

Перед реальным использованием поменяйте `app.secret_key`.
