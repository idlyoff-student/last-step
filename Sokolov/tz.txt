Техническое задание

Информационная система учёта заказов кофейни

1. Общая информация

Разработать веб-приложение для условной кофейни с несколькими филиалами.

Система предназначена для автоматизации оформления, учёта и обработки заказов, управления меню и контроля работы сотрудников.

2. Технологии

• Python — основной язык программирования.
• Flask — серверная часть.
• SQLite — база данных.
• HTML, CSS — интерфейс.
• JavaScript — интерактивные элементы.

3. Основной функционал

Авторизация пользователей:

• Вход по логину и паролю.
• Создание учётных записей.
• Выход из аккаунта.
• Разграничение прав доступа.
• Восстановление пароля через контрольный вопрос и ответ.

Управление меню:

• Добавление товаров.
• Редактирование товаров.
• Удаление товаров.
• Указание названия, описания, категории и цены.
• Управление доступностью товаров.

Управление заказами:

• Создание новых заказов.
• Добавление нескольких товаров в заказ.
• Изменение количества товаров.
• Автоматический расчёт стоимости.
• Добавление комментариев.
• Изменение статуса заказа.
• Просмотр истории заказов.

Статусы заказов:

• Новый.
• Готовится.
• Готов.
• Выдан.
• Отменён.

4. Отдельный экран заказов

Создать отдельную страницу для отображения заказов на мониторе или телевизоре внутри кофейни.

Требования:

• Отображение номера заказа.
• Отображение состава заказа.
• Отображение текущего статуса.
• Автоматическое обновление информации.
• Удобный интерфейс для широкоформатных экранов.
• Отображение только актуальных заказов.

5. База данных

Использовать SQLite.

Предусмотреть следующие таблицы:

• Users — пользователи.
• Products — товары.
• Categories — категории товаров.
• Orders — заказы.
• OrderItems — состав заказов.
• Branches — филиалы.

6. Интерфейс

Создать современный, минималистичный и удобный интерфейс.

Основные требования:

• Понятная навигация.
• Единый стиль страниц.
• Удобные формы и таблицы.
• Отображение статусов заказов.
• Адаптация под разные разрешения экранов.

7. Требования к результату

Необходимо создать полноценное работающее веб-приложение.

Все основные функции должны быть реализованы и связаны с базой данных. Информация должна сохраняться после перезапуска приложения.

Проект должен запускаться локально на Windows и иметь инструкцию по установке и запуску.
